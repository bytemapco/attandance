## Set up a new institution
Role: admin
Page: /admin/onboarding
The setup checklist lists what must exist before attendance can run: departments, subjects, classrooms, teachers, classes with subjects and a timetable, and the campus location. Work from the top. Each item links to the page that fixes it. Press Complete setup when the required items are done.

## Add departments, subjects, classrooms and designations
Role: admin
Page: /admin/master-data
Open Master data and pick the tab. Add one at a time, or import many from a CSV. Departments come first, because subjects, teachers and students belong to one.

## Add students or teachers
Role: admin
Page: /admin/users/students
Open Users, then Students or Teachers. Add one person with the form, or import a CSV. New people get an invitation e-mail to set a password. A student does not choose a semester: it comes from their class.

## Create a class and add subjects
Role: admin
Page: /admin/class-management
A class is a department plus a batch, with a semester number. A student added to a batch joins that batch's class by themselves. If the batch has no class yet, create it first, or the student sees no timetable. Open the class, add each subject with its teacher, then add the weekly schedule rows for that subject.

## Change a class's semester
Role: admin
Page: /admin/class-management
Open the class and edit the semester number. There is no promotion step. Students move to the next semester when you change the class.

## Set the campus location and attendance rules
Role: admin
Page: /admin/settings
Settings holds the campus map point and radius used for location checks, the minimum attendance percentage, how long the attendance window stays open, and whether Saturday is a class day. These rules apply to the whole institution. Only the admin screen changes them. The assistant cannot.

## See attendance reports and download them
Role: admin
Page: /admin/reports
Pick a class, then the shortage list, the register for one subject, or the subject summary. Choose dates if you want a period. Download as Excel or PDF from the same page.

## Seats and licences
Role: admin
Page: /admin/licenses
Licences shows how many seats your institution has and how many are used. Ask for more seats from the same page.
